# Catálogo Inicial de Produtos PCTEC

Os seguintes produtos deverão ser avaliados como consumidores, provedores de dados ou integrações do PCTEC Ingressa:

- PCTEC-HELPDESK
- PCTEC-PROTECT
- PCTEC-OMIE
- PCTEC-PARTNERS
- PCTEC-PORTAL
- PCTEC-JIRA
- PCTEC-CLAIM
- PCTEC-EXCHANGE
- PCTEC-TOMTICKET

## Classificação inicial a confirmar

| Produto | Papel provável |
|---|---|
| PCTEC-PORTAL | Primeiro consumidor de autenticação central e organizações |
| PCTEC-HELPDESK | Consumidor de identidades e organizações |
| PCTEC-PROTECT | Consumidor de identidades, aplicações ou contas técnicas |
| PCTEC-OMIE | Ingressação/connector; escopo de identidade a confirmar |
| PCTEC-PARTNERS | Consumidor para parceiros e organizações |
| PCTEC-JIRA | Consumidor interno ou integração |
| PCTEC-CLAIM | Consumidor de identidades e organizações |
| PCTEC-EXCHANGE | Ingressação ou aplicação consumidora |
| PCTEC-TOMTICKET | Ingressação de atendimento e identidades |

A classificação acima é preliminar e deve ser validada durante o levantamento de cada produto.
